# 变更记录 18：箭头尺寸与边界留白

对应 `docs/agents/basic-info.md` 中 Priority 第 14 条：**UI 优化：调整箭头大小，与边界保持一定间隔**。

## 问题：箭头几乎填满格子

上一轮（事项 12/13）把画布从“钉死的 720²”改成按窗口等比缩放、又给所有弧线加了超采样
之后，格子被放大了，原来“箭头填满格子”的比例就露出来了：圆片半径是格子内边宽的 **0.44**，
箭头图形的最大外延又是内边宽的 **0.42**——圆片离格子边框只剩 6%、图形离圆片外沿只剩 2px。
于是棋盘上的观感是“一格格挤满圆片”，箭头几乎贴着格子边框（而最外圈格子离棋盘底板边缘
本来就只有 `CELL_GAP = 6`），放大窗口后更明显。

## 变更内容

| 文件 | 修改 |

## 关键设计

### 一处比例、一个入口

“箭头画多大”现在只由两个常量决定，且都被一个函数算出来：

```text
圆片半径 = 格子内边宽 × ARROW_CHIP_RATIO          （Board.chip_radius）
图形外延 = 圆片半径    × ARROW_GLYPH_RATIO        （_arrow_sprite）
留白     = 格子内边宽 / 2 − 圆片半径
```

`Board.chip_radius(row, col)` 是唯一的取值入口：箭头贴图、选中呼吸环、碰撞红环、
辅助线的起点与终点、挡住提示环、碰撞火花都按它推位置。改比例时不会有“某处还按老半径
画”的错位——这也是把 `_ARROW_SHAPE` 的基准从格子尺寸换成圆片半径的原因：图形缩放不再
独立于圆片，**图形一定装在圆片里**。

### 数值取舍

| 比例 | 圆片离格子边框 | 图形尖端离格子边框 | 观感 |
| --- | --- | --- | --- |
| 0.44 / 0.95（旧） | 内边宽 × 6% | 内边宽 × 8%（只比圆片外沿收进 2px） | 圆片与图形都顶到边，格子被填满 |
| **0.40 / 0.88（现）** | **内边宽 × 10%** | **内边宽 × 14.8%**（比圆片外沿收进 12% 半径） | 箭头稳稳坐在格子里，图形与圆片之间也有一圈可见的底 |
| 0.37 / 0.88 | 内边宽 × 13% | 内边宽 × 17.4% | 箭头明显偏小，6×6 的格子里显空 |

格子的内边宽只有 80 ~ 100px（4×4 的 112 顶格，到 6×6 的 92），因此实际留白是
**8 ~ 10px**：肉眼能看出“箭头没贴着边”，又不至于小到看不清朝向。因为比例是相对量，
窗口放大后留白按同一个系数变大，格子越大间隔越明显（这正是想要的——格子越大越不该挤）。

### 火花跟着箭头收

碰撞火花原来的长度按**格子尺寸**取，箭头缩小后就会显得“火花比箭头还长”。现在
`_draw_impact_sparks()` 收圆片半径，长度改成 `半径 × (0.15 + 0.35 × 包络)`，
与半径同比例缩放；起点仍是 `半径 × 1.02`（紧贴圆片外沿）。

## 验证

```powershell
uv run pytest -q                      # 408 passed
uv run ruff check . ; uv run ruff format --check . ; uv run ty check
uv run python .preview/arrow_size.py  # 三档对照图 .preview/arrow-size-zoom.png
uv run python .preview/ui_frames.py   # 重新生成界面截图（辅助线 / 碰撞提示都仍然对齐）
uv run python .preview/run_demo.py    # dummy 驱动下跑真实主循环冒烟
```

- 新增的 `test_arrows_keep_a_gap_from_the_cell_border` 量的是**真正画出来的像素**：沿格子
  四条中线从边框往里扫，第一条不是格子底色的像素就是圆片外沿，它对每一关都要求
  ≥ 内边宽 × 8%。把 `ARROW_CHIP_RATIO` 改回 0.44 跑这条测试会失败
  （`第 1 关：箭头离格子边框只有 6px（内边宽 100px，下限 8.0px）`），因此它确实钉住了
  “箭头不能填满格子”，而不是只对着常量做断言。
- 对照图 `.preview/arrow-size-zoom.png` 是 6×6 棋盘左上角 2×2 格子放大 3 倍的三档并排：
  最左（旧）圆片几乎顶到格子圆角，中间（现）四周留白均匀、图形外还有一圈圆片底色，
  最右明显偏小。
- 辅助线仍然“从圆片外沿起、到挡路箭头外沿或棋盘边缘止”，只是随半径一起收；
  `tests/test_board.py` 的辅助线几何测试已改成读 `chip_radius`，不再有硬编码比例。

## 后续

- 想要更大的箭头只需调 `ARROW_CHIP_RATIO`（0.42 以内都还能过那条 8% 的像素测试）；
  想调“图形在圆片里占多少”就动 `ARROW_GLYPH_RATIO`（不要超过 1.0，图形会画出圆片）。
- 新画与箭头圆片对齐的提示（环、线、箭头）时，请用 `Board.chip_radius()`，不要再写
  `cell.width * 比例`。
