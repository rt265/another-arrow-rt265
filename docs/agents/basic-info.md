
# Basic Info

“一箭又一箭”是一类点击式箭头解谜游戏。玩家需要观察箭头的方向和相互阻挡关系，按照合适的顺序点击箭头，使所有箭头依次飞出棋盘。

## Arrows Check

游戏棋盘中包含若干带方向的箭头，箭头方向分为上、下、左、右四种。玩家点击某个箭头后，程序检查该箭头前进方向上的路径：

1. 如果箭头与棋盘边界之间没有其他箭头阻挡，该箭头飞出棋盘并被消除；
2. 如果路径上存在其他箭头，该箭头不能被消除，并通过移动后返回、晃动、变色或文字等方式提示碰撞；
3. 点击被阻挡的箭头会消耗一次失误机会；
4. 清除本关全部箭头后即可进入下一关；
5. 失误次数耗尽时，本关失败，可重新开始。

基础实现采用网格中的单格箭头，路径检测只需判断同一行或同一列、箭头与边界之间是否还有其他箭头。

## Functions

程序至少应实现以下功能：

1. 具有可以正常显示和操作的图形化游戏界面；
2. 棋盘中包含上、下、左、右四种方向的箭头；
3. 能够通过鼠标点击选择箭头；
4. 能够正确判断箭头前进方向上是否存在其他箭头；
5. 前方无阻挡时，箭头能够飞出棋盘并消失；
6. 前方有阻挡时，箭头不能消失，并给出明显的碰撞反馈；
7. 设置失误次数，并在界面中显示剩余次数；
8. 至少设计 3 个可以正常通关的关卡；
9. 清空当前关卡全部箭头后，能够显示通关结果并进入下一关；
10. 失误次数耗尽时，能够显示失败结果；
11. 提供重新开始功能，使当前关卡恢复到初始状态。
