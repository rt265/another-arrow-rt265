# Player Guide

“一箭又一箭”（Another Arrow）是一款点击式箭头解谜游戏：棋盘上摆着若干带方向的箭头，点中一支箭头，它就会沿自己的朝向飞出去——前提是这条路上没有别的箭头。

## 游戏规则

1. 点中一支箭头后，程序检查它**前进方向上**的路径；
2. 前方到棋盘边界之间**没有其他箭头** → 它沿该方向飞出棋盘并消失；
3. 前方有箭头挡路 → 它飞不出去，会抖动一下并溅出火花，同时**消耗一次失误机会**；
4. 每关共 **3 次失误机会**（信息栏用圆点显示，亮色的是剩余次数）；
5. 清空本关全部箭头 → 通关，可进入下一关（并记录本关用时）；
6. 失误次数耗尽 → 本关失败，可重试本关。

内置 10 关，难度逐关递增；**第 1 关是交互式教程**，会一步步教你上面这几条。

## 屏幕与读数

游戏画面上方是信息栏，从左到右依次是：

| 位置 | 内容 |
|--|--|
| 左上角 | 图标按钮：回到主界面 |
| 第 1 格 | 关卡：当前关号 / 总关数 |
| 第 2 格 | 剩余箭头 |
| 第 3 格 | 用时 |
| 第 4 格 | 失误：三颗圆点，亮色为剩余次数 |
| 右侧 | “重新开始”按钮 |

棋盘右下角还有一颗**辅助线**开关。

清空棋盘或失误耗尽后，棋盘上方会叠出一张结算卡片：

- 通关：标题“关卡完成！”，正文报告剩余失误次数，并给出本关用时；非最后一关的主按钮是“下一关”，最后一关则是“再来一轮”（回到第 1 关重新开始）；
- 失败：标题“挑战失败”，主按钮是“重试本关”，本关箭头布局与失误次数都会恢复到初始状态。

两张卡片上都有“回到主界面”。

## 操作

| 操作 | 鼠标 |
|--|--|
| 点击箭头 | 左键单击箭头 |
| 触发当前画面的主按钮（开始游戏 / 下一关 / 重试本关） | 点击该按钮 |
| 重新开始本关 | 信息栏右侧“重新开始” |
| 回到主界面 | 信息栏左上角图标、结算卡片的“回到主界面” |
| 打开 / 关闭设置 | 开始界面页脚的“设置” |
| 开关辅助线 | 棋盘右下角的开关 |
| 上一关 / 下一关 | — |
| 退出游戏 | 关闭窗口 |

## 计时与成绩

- 每关单独计时，**只在解谜过程中走字**：清空棋盘的瞬间就停表，之后的飞出动画与结算停顿都不计入。停在开始界面或设置界面也不会让时间流逝。
- 通关卡片上报告本关用时；如果这一把刷新了本关最快成绩，会显示“新纪录”，否则与最佳成绩并排显示。
- 最佳成绩按关卡记在**本次运行**里，重开本关、回到主界面、甚至通完一轮再从头玩，成绩都还在；关闭程序后不再保留。

## 辅助线

辅助线是一个可选功能，**默认关闭**，用右下角的开关打开。打开后，每支箭头都会沿自己当前的前进方向拉一条虚线，虚线的终点就是这一箭会停下的地方：

- 顶到棋盘边缘（绿色）→ 前方畅通，点得动；
- 停在另一支箭头上（红色）→ 被挡住，点不动。

鼠标指着的那条线会比其他的更亮。辅助线只是参考，它不参与任何判定，既不会帮你扣失误，也不会替你出手。

## 第 1 关的教程

每一次开局，第 1 关都会带你走三步：

1. 点击前方畅通的箭头，看它飞出棋盘；
2. 点击被挡住的箭头，看碰撞反馈——**这一次是演示，不扣失误**；
3. 继续点击清空棋盘，完成本关。

提示条右侧有“跳过教程”按钮。走完或跳过之后，本局再回到第 1 关它都不会出现；反过来，如果第 1 关没通过而教程还没走完，重试时会从第一步重新讲一遍。

## 设置

开始界面页脚的“设置”按钮可以打开设置界面，里面有两个开关：

- **背景音乐**：从打开窗口起循环播放；
- **音效**：按钮、箭头飞出、撞墙、通关与失败各有一声提示音。

两项初始都是打开的，只对本次运行有效——关闭程序后恢复默认，不做保存。

## 窗口

窗口可以自由缩放：拖拽边框、最大化都可以。界面（棋盘、文字、按钮）会等比放大并居中留白，不会拉伸变形；缩放过程中关卡进度、失误次数、用时与教程进度都不会丢失。
