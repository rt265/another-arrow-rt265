# Another Arrow

本项目为福州大学 2026 年软件工程课程的项目，配合 Agent 开发小游戏。

> [!note]
>
>  本项目仅为学习研究使用，不涉及任何商业用途，也不建议在生产环境中使用。

## Tech Stack

- Python 3.13
- UV
- Ruff
- ty

## Development

使用 [UV](https://docs.astral.sh/uv/getting-started/installation/) 安装项目：

```bash
uv sync
```

启动项目：

```bash
another-arrow-rt265
```

Lint：

```bash
ruff check .
```

Format:

```bash
ruff format --check .
```

Type Check:

```bash
ty check
```
